# Retail Business SQL Project

## Project Overview

This project is a retail business database and sales analysis project developed using MySQL.

The project demonstrates database creation, table relationships, data management, SQL queries, joins, aggregations, and business analysis.

## Technologies Used

- MySQL
- SQL

## Database Tables

- Customers
- Products
- Orders
- OrderDetails

## Key Analysis

- Total customers
- Total products
- Total orders
- Total sales
- Average order value
- Product-wise sales
- Category-wise sales
- Customer-wise spending
- Top-selling product
- Payment method analysis
- State-wise customer analysis
- Gender-wise customer analysis
- Age-group analysis
- Monthly sales analysis

## SQL Concepts Used

- Database and table creation
- Primary keys
- Foreign keys
- Constraints
- INSERT
- SELECT
- JOIN
- GROUP BY
- HAVING
- ORDER BY
- Aggregate functions
- CASE
- LIMIT
- VIEW

## Project Objective

To analyze retail business data using SQL and generate meaningful insights about customers, products, orders, sales, and business performance.
